# স্টুডেন্ট ফোরাম ওয়েবসাইট — সেটআপ গাইড

এই ওয়েবসাইটটি সম্পূর্ণভাবে **GitHub Pages** (হোস্টিং) এবং **Google Sheets** (ডাটাবেস) দিয়ে চলবে। কোনো টাকা খরচ ছাড়াই সম্পূর্ণ ফ্রি।

---

## ধাপ ১: Google Sheet তৈরি করুন

1. [Google Sheets](https://sheets.google.com) এ গিয়ে একটি নতুন স্প্রেডশিট বানান। নাম দিন যেমন **"Student Forum Database"**।
2. উপরে মেনু থেকে **Extensions → Apps Script** এ ক্লিক করুন।
3. যে এডিটর খুলবে, সেখানে থাকা ডিফল্ট কোড মুছে দিয়ে এই প্রজেক্টের `AppsScript_Code.gs` ফাইলের সম্পূর্ণ কোড কপি-পেস্ট করুন।
4. উপরে থাকা **Save** (ফ্লপি ডিস্ক আইকন) এ ক্লিক করুন। প্রজেক্টের একটা নাম দিন, যেমন "Forum Backend"।
5. ফাংশন ড্রপডাউন থেকে **`setupSheets`** নির্বাচন করে **Run** বাটনে ক্লিক করুন।
   - প্রথমবার একটা পারমিশন চাইবে। **Advanced → Go to Forum Backend (unsafe) → Allow** ক্লিক করুন। (এটা আপনার নিজের স্ক্রিপ্ট, তাই নিরাপদ)
6. এটা রান হলে আপনার Google Sheet-এ স্বয়ংক্রিয়ভাবে সাতটি শীট তৈরি হয়ে যাবে: `Students`, `Teachers`, `Committee`, `SpecialCommittee`, `ForumInfo`, `Settings`, `Admin`।
7. Sheet-এ ফিরে গিয়ে `Settings` শীটে দেখুন `AdminPassword` এর মান `changeme123` আছে — এটা পরে ওয়েবসাইটের ব্যবস্থাপনা মেনু থেকে পরিবর্তন করে নেবেন।

## ধাপ ২: Web App হিসেবে Deploy করুন

1. Apps Script এডিটরে উপরে ডান দিকে **Deploy → New deployment** ক্লিক করুন।
2. গিয়ারের আইকনে ক্লিক করে **Web app** নির্বাচন করুন।
3. সেটিংস দিন:
   - **Execute as**: `Me (আপনার ইমেইল)`
   - **Who has access**: `Anyone`
4. **Deploy** ক্লিক করুন।
5. যে URL পাবেন (যেমন `https://script.google.com/macros/s/AKfycb.../exec`) সেটি **কপি করে রাখুন** — এটাই আপনার API URL।

> ⚠️ ভবিষ্যতে `AppsScript_Code.gs` ফাইলে কোনো পরিবর্তন করলে, **Deploy → Manage deployments → Edit (পেন্সিল আইকন) → Version: New version → Deploy** করে আবার আপডেট করতে হবে। URL একই থাকবে।

## ধাপ ৩: ওয়েবসাইটের config.js আপডেট করুন

`config.js` ফাইলটি খুলুন এবং এই লাইনটি খুঁজুন:

```javascript
API_URL: 'YOUR_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE',
```

এটি পরিবর্তন করে আপনার কপি করা URL বসান:

```javascript
API_URL: 'https://script.google.com/macros/s/AKfycb.../exec',
```

সংরক্ষণ করুন।

## ধাপ ৪: GitHub Pages এ হোস্ট করুন

1. [GitHub](https://github.com) এ একটি নতুন রিপোজিটরি বানান (যেমন `student-forum`)। **Public** রাখতে হবে।
2. এই প্রজেক্টের সব ফাইল (`index.html`, `config.js`, `css/`, `js/` ফোল্ডার) রিপোজিটরিতে আপলোড করুন।
   - GitHub ওয়েবসাইটে গিয়ে "Add file → Upload files" দিয়েও করা যায়, অথবা Git কমান্ড লাইন দিয়ে।
3. রিপোজিটরির **Settings → Pages** এ যান।
4. **Source**: `Deploy from a branch` নির্বাচন করুন।
5. **Branch**: `main` এবং ফোল্ডার `/ (root)` নির্বাচন করে **Save** করুন।
6. কয়েক মিনিট পর আপনার সাইট লাইভ হবে এই ঠিকানায়:
   `https://[আপনার-ইউজারনেম].github.io/student-forum/`

## ধাপ ৫: প্রথম লগইন ও তথ্য সেট করুন

1. লাইভ সাইটে গিয়ে **ব্যবস্থাপনা** মেনুতে ক্লিক করুন।
2. পাসওয়ার্ড দিন: `changeme123` (Sheet এর Settings ট্যাবে যা সেট করেছিলেন)
3. **ফোরাম তথ্য** ট্যাবে গিয়ে আপনার প্রতিষ্ঠানের নাম, লোগো, স্লোগান ইত্যাদি দিয়ে **সংরক্ষণ করুন**।
4. **পাসওয়ার্ড** ট্যাব থেকে ডিফল্ট পাসওয়ার্ড পরিবর্তন করে একটি শক্তিশালী পাসওয়ার্ড দিন।
5. **কমিটি তথ্য** ট্যাবে কমিটির সদস্যদের যোগ করুন (নাম লিখলে আগে থেকে রেজিষ্ট্রেশনকৃত শিক্ষার্থীদের নাম সাজেশন হিসেবে আসবে, নির্বাচন করলে মোবাইল নং অটো বসে যাবে)।

## গুরুত্বপূর্ণ নোট

- **রেজিষ্ট্রেশন নম্বর**: প্রতি শিক্ষার্থীর জন্য `SRN` + প্রতিষ্ঠাকাল + ক্রমিক সংখ্যা (যেমন `SRN19850001`) এবং শিক্ষকের জন্য `TRN` + প্রতিষ্ঠাকাল + ক্রমিক সংখ্যা স্বয়ংক্রিয়ভাবে তৈরি হয়। **ব্যবস্থাপনা → ফোরাম তথ্য** থেকে "প্রতিষ্ঠাকাল" ফিল্ডটি অবশ্যই আগে পূরণ করে রাখুন, তাহলে রেজিষ্ট্রেশন নম্বর সঠিকভাবে তৈরি হবে।
- **নিজে তথ্য হালনাগাদ**: শিক্ষার্থী/শিক্ষক নিজে "শিক্ষার্থী → তথ্য হালনাগাদ" (বা শিক্ষক) মেনু থেকে নাম সার্চ করে, রেজিষ্ট্রেশনের সময় দেওয়া মোবাইল নম্বর দিয়ে যাচাই করে নিজের তথ্য এডিট করতে পারবে। মোবাইল না মিললে এডিট করা যাবে না — এতে একজনের ডাটা অন্যজন এডিট করতে পারবে না।
- **অ্যাডমিন রেকর্ড এডিট**: **ব্যবস্থাপনা → রেকর্ড এডিট** থেকে মোবাইল যাচাই ছাড়াই সরাসরি নাম সার্চ করে যেকোনো শিক্ষার্থী/শিক্ষকের তথ্য এডিট করা যাবে।
- **মোবাইল মেনু**: ছোট স্ক্রিনে হেডারে ৩-লাইন (হ্যামবার্গার) আইকন দেখাবে — ট্যাপ করলে মেনু খুলবে, আবার ট্যাপ করলে বা কোনো মেনু আইটেমে ক্লিক করলে বন্ধ হয়ে যাবে।
- **ব্যবস্থাপনা মেনুর ফরম বাটন**: প্রতিটি ট্যাব এখন টগল বাটনের মতো কাজ করে — ক্লিক করলে খুলবে, একই বাটনে আবার ক্লিক করলে বা অন্য বাটনে ক্লিক করলে আগেরটা বন্ধ হয়ে যাবে।
- **এডিট সুবিধা**: শিক্ষার্থী/শিক্ষক প্রোফাইল থেকে "বিস্তারিত দেখুন" এ ক্লিক করে "এডিট করুন" বাটনে যেকোনো তথ্য সংশোধন করা যাবে। রেজিষ্ট্রেশনের পর প্রিন্ট কপিতেও "এডিট করুন" বাটন থাকবে।
- **তালিকা প্রিন্ট**: **ব্যবস্থাপনা → তালিকা প্রিন্ট** থেকে শিক্ষার্থী/শিক্ষক তালিকা (ক্রম, নাম, ব্যাচ, পেশা, মোবাইল, ঠিকানা কলাম সহ) প্রিন্ট করা যাবে, চাইলে "প্রাক্তন"/"বর্তমান" ফিল্টার করেও।
- **অনুষ্ঠান মডিউল**: **ব্যবস্থাপনা → অনুষ্ঠান** থেকে নতুন অনুষ্ঠান তৈরি করুন। শিক্ষার্থী/শিক্ষকরা "অনুষ্ঠান" মেনু থেকে অংশগ্রহণের জন্য রেজিষ্ট্রেশন করতে পারবে (নিজেদের SRN/TRN রেজিষ্ট্রেশন আইডি দিয়ে, যা আগে থেকে প্রোফাইল তৈরি না থাকলে কাজ করবে না)। জমা দেওয়া রেজিষ্ট্রেশন প্রথমে "পেন্ডিং" থাকবে — **ব্যবস্থাপনা → অনুষ্ঠান → রেজিষ্ট্রেশন অনুমোদন** থেকে "নিশ্চিত করুন" চাপলে সংশ্লিষ্ট ব্যক্তি রেজিষ্ট্রেশন কার্ড ডাউনলোড করতে পারবে।
- **ছবি আপলোড**: শিক্ষার্থী/শিক্ষকের ছবি ও স্বাক্ষর Google Drive-এ `StudentForumUploads` নামে একটি ফোল্ডারে সংরক্ষিত হবে (Apps Script যে Google অ্যাকাউন্ট দিয়ে ডিপ্লয় করেছেন, তার Drive-এ)। ছবির সাইজ ৪MB এর কম রাখুন।
- **ডেমো মোড**: যতক্ষণ `index.html`-এর শুরুর দিকে থাকা `CONFIG` অবজেক্টে সঠিক API URL না বসাবেন, ততক্ষণ সাইট নমুনা ডাটা দিয়ে চলবে — যাতে ডিজাইন দেখতে পারেন। এটি শুধু ব্রাউজারের মেমোরিতে থাকে, রিফ্রেশ দিলে হারিয়ে যাবে।
- **নিরাপত্তা**: এই পাসওয়ার্ড সিস্টেমটি সাধারণ (Sheet-ভিত্তিক)। এটি ছোট প্রতিষ্ঠানের জন্য যথেষ্ট, তবে অতি স্পর্শকাতর তথ্যের জন্য উপযুক্ত নয়। পাসওয়ার্ড কারো সাথে শেয়ার করবেন না।
- **সীমাবদ্ধতা**: Google Apps Script Web App প্রতিদিন ফ্রি অ্যাকাউন্টে প্রায় ২০,০০০ রিকোয়েস্ট পর্যন্ত সাপোর্ট করে — একটি প্রতিষ্ঠানের ফোরামের জন্য যথেষ্ট বেশি।
- **কাস্টম ডোমেইন**: পরবর্তীতে নিজস্ব ডোমেইন (যেমন `alfalahforum.com`) যুক্ত করতে চাইলে GitHub Pages Settings-এ Custom domain অপশন ব্যবহার করতে পারবেন — কোড পরিবর্তনের দরকার নেই।

## ⚠️ কোড পরিবর্তন করার পর অবশ্যই করণীয়

`AppsScript_Code.gs`-এ যেকোনো পরিবর্তনের (এই আপডেটে `Events` শীটে ৫টি নতুন কলাম যোগ হয়েছে — `FeeType`, `FeeStudentFormer`, `FeeStudentCurrent`, `FeeTeacherFormer`, `FeeTeacherCurrent` — যাতে অনুষ্ঠানের ফি "সকল" এর জন্য এক রকম বা ধরনভিত্তিক (প্রাক্তন/বর্তমান শিক্ষার্থী/শিক্ষক) আলাদা আলাদা নির্ধারণ করা যায়) পর:
1. Google Sheet এর Apps Script এডিটরে গিয়ে **পুরনো কোড মুছে নতুন কোড পেস্ট করুন**
2. ফাংশন ড্রপডাউন থেকে `setupSheets` চালিয়ে নতুন শীট/কলাম যোগ করে নিন (আগের ডাটা মুছবে না, শুধু নতুন শীট/কলাম হেডার যোগ হবে যদি আগে থেকে না থাকে)
3. **Deploy → Manage deployments → Edit (পেন্সিল) → Version: New version → Deploy** করে নতুন ভার্সন লাইভ করুন (URL অপরিবর্তিত থাকবে)

### এই আপডেটে যা ঠিক/যোগ করা হয়েছে
- **তারিখ ফরম্যাট বাগ ঠিক করা হয়েছে**: আগে কিছু তারিখ `2026-08-20T18:00:00.000Z` এর মতো কাঁচা ফরম্যাটে দেখাচ্ছিল। এখন ব্যাকএন্ড (`getSheetAsObjects`) কলামের নাম অনুযায়ী তারিখ ফরম্যাট করে (`...DateTime` কলামে সময়সহ, বাকিগুলোতে শুধু তারিখ), এবং ফ্রন্টএন্ডেও একটি নিরাপদ `formatDateOnly()` ফাংশন সব জায়গায় ব্যবহার করা হয়েছে যাতে পুরনো ডাটাতেও তারিখ ঠিকভাবে বাংলায় দেখায়।
- **ফি নির্ধারণ ফরমে "সকল" যোগ**: এখন ধরন নির্বাচনে "সকল" অপশন আছে — এটি নির্বাচন করে একটি ফি দিলে তা সব ধরনের (প্রাক্তন/বর্তমান শিক্ষার্থী/শিক্ষক) জন্য প্রযোজ্য হবে, যদি না কোনো নির্দিষ্ট ধরনের জন্য পরে আরও নতুন তারিখের ফি আলাদাভাবে নির্ধারণ করা হয়।
- **অনুষ্ঠান ফরমে ৫ ধরনের ফি ক্যাটাগরি**: নতুন অনুষ্ঠান তৈরির ফরমে এখন "ফি এর ধরন" নির্বাচন করা যায় — সকল, প্রাক্তন শিক্ষার্থী, বর্তমান শিক্ষার্থী, প্রাক্তন শিক্ষক, বর্তমান শিক্ষক। "সকল" নির্বাচন করলে একটি মাত্র ফি সবার জন্য প্রযোজ্য হবে; নির্দিষ্ট কোনো ধরন নির্বাচন করলে ৪টি আলাদা ফি ইনপুট দেখাবে, যাতে প্রতিটি ক্যাটাগরির জন্য আলাদা ফি দেওয়া যায় (খালি রাখলে সেই ক্যাটাগরির জন্য ফ্রি ধরা হবে)। রেজিষ্ট্রেশনের সময় ব্যক্তির ধরন অনুযায়ী স্বয়ংক্রিয়ভাবে সঠিক ফি বসে যাবে।
- **টেবিল অ্যালাইনমেন্ট**: সাইটের সব টেবিলের হেডার ও ডাটা এখন মাঝ বরাবর (center) দেখাবে, শুধু নাম/অনুষ্ঠানের নামের কলামের ডাটা বামে (left) দেখাবে — যেমন রেজিষ্ট্রেশন অনুমোদন, কমিটি তালিকা, ফি প্রদানের অনুমোদন, আয়ের তালিকা ইত্যাদি টেবিলে।
### সর্বশেষ আপডেট
- **ফি প্রদানের অনুমোদন টেবিলে "বাতিল করুন" বাটন** যোগ হয়েছে — পেন্ডিং প্রতিটি অনুরোধে এখন "নিশ্চিত করুন" এর পাশে "বাতিল করুন" বাটন থাকবে। বাতিল করলে অবস্থা "❌ বাতিল" দেখাবে (রেকর্ড মুছে যাবে না, শুধু স্ট্যাটাস পরিবর্তন হবে)।
- **অনুষ্ঠান ফরম ও ফি নির্ধারণ ফরম — উভয় জায়গায় "ফি এর ধরন" এখন ২টি অপশন**: "সবার জন্য সমান" (একটি মাত্র ফি সবার জন্য প্রযোজ্য) এবং "প্রত্যেকের আলাদা" (নির্বাচন করলে ৪টি বক্স আসবে — শিক্ষার্থী (প্রাক্তন), শিক্ষার্থী (বর্তমান), শিক্ষক (প্রাক্তন), শিক্ষক (বর্তমান) — যার যেটাতে ফি দরকার শুধু সেটা পূরণ করলেই চলবে)।
  - ফি নির্ধারণ ফরমে "প্রত্যেকের আলাদা" দিয়ে একসাথে একাধিক বক্সে মান দিলে প্রতিটির জন্য আলাদা আলাদা রেকর্ড তৈরি হবে, সবগুলোর কার্যকরের তারিখ একই থাকবে।

এই আপডেটে ব্যাকএন্ডে নতুন একটি অ্যাকশন যোগ হয়েছে (`rejectFeePayment`), তাই আবারও **নতুন ভার্সন Deploy করা আবশ্যক** (উপরের ধাপ অনুসরণ করুন)।

### সর্বশেষ আপডেট (২)
- **অনুষ্ঠান তালিকা কার্ড-প্রস্থ দেখানোর বাগ ঠিক করা হয়েছে**: `eventsListGrid` কন্টেইনারে ভুলবশত `people-grid` ক্লাস (CSS grid, `minmax(160px, 1fr)`) বসানো ছিল, যার কারণে ভেতরের টেবিলটি পুরো প্রস্থ না নিয়ে একটি সংকীর্ণ কলামে সীমাবদ্ধ হয়ে যাচ্ছিল। ক্লাসটি সরিয়ে দেওয়া হয়েছে; এখন টেবিল স্বাভাবিকভাবে পুরো প্রস্থ জুড়ে দেখাবে।
- **অনুষ্ঠান রেজিষ্ট্রেশন কার্ডের ব্যাকগ্রাউন্ড ডিজাইন সরানো হয়েছে**: কার্ডের পেছনে থাকা সজ্জিত ছবি (background image) বাদ দিয়ে সাদা ব্যাকগ্রাউন্ড রাখা হয়েছে (বর্ডার আগের মতোই আছে)।
- **শিক্ষার্থী/শিক্ষক প্রিন্ট কপির ব্যাকগ্রাউন্ড ডিজাইন সরানো হয়েছে**: "পার্চমেন্ট" থিমের সাজসজ্জামূলক গ্র্যাডিয়েন্ট/রং বাদ দিয়ে সাদা ব্যাকগ্রাউন্ড রাখা হয়েছে (বর্ডার ও লেআউট অপরিবর্তিত)।

### সর্বশেষ আপডেট (৩)
- **শিক্ষার্থী রেজিষ্ট্রেশন কপি**তে গোলাকার কোণ (border-radius) যোগ করা হয়েছে — কার্ড ও ভেতরের বর্ডার দুটোই এখন গোলাকার শেপে দেখাবে (এটি শিক্ষক রেজিষ্ট্রেশন কপিতেও একই রকম প্রযোজ্য, যেহেতু দুটোই একই ডিজাইন শেয়ার করে)।
- **অনুষ্ঠান রেজিস্ট্রেশন কার্ড**: শিরোনাম (অনুষ্ঠানের নাম ব্যাজ) এর উপরের অতিরিক্ত গ্যাপ কমানো হয়েছে (ছবির বক্সের উচ্চতা কমিয়ে ও মার্জিন টাইট করে), এবং শিরোনামের ব্যাজ শেপেও এখন border-radius (গোলাকার কোণ) যোগ করা হয়েছে।
- **শিক্ষার্থী/শিক্ষক রেজিষ্ট্রেশন পাতা রিডিজাইন**: এখন রেজিষ্ট্রেশন ফরমটি একটি বাটনের পেছনে থাকে — বাটনে ক্লিক করলে ফরম দেখাবে, আবার ক্লিক করলে বন্ধ হবে (পাতা প্রথমবার খুললে ফরম বন্ধ অবস্থায় থাকবে)। ফরমের নিচে ইতিমধ্যে রেজিষ্ট্রেশনকৃত সবার একটি সার্চ/ফিল্টারযোগ্য তালিকা (টেবিল আকারে) দেখা যাবে, এবং প্রতিটি সারিতে **এডিট**, **প্রিন্ট**, ও **ডিলেট** বাটন আছে।
  - **এডিট** করলে ফরম খুলে সংশ্লিষ্ট তথ্য পূরণ হয়ে যাবে।
  - **প্রিন্ট** করলে সরাসরি সেই ব্যক্তির রেজিষ্ট্রেশন কপি দেখাবে/প্রিন্ট করা যাবে।
  - **ডিলেট** করতে নিশ্চিতকরণ ও **ব্যবস্থাপনার পাসওয়ার্ড** লাগবে (নিরাপত্তার জন্য) — সঠিক পাসওয়ার্ড ছাড়া কেউ কারো রেজিষ্ট্রেশন মুছতে পারবে না।

⚠️ এই আপডেটে ব্যাকএন্ডে দুটি নতুন প্রোটেক্টেড অ্যাকশন যোগ হয়েছে (`deleteStudent`, `deleteTeacher`), তাই আবারও `AppsScript_Code.gs` কোড বসিয়ে **নতুন ভার্সন Deploy করা আবশ্যক**।
