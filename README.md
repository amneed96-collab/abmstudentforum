# স্টুডেন্ট ফোরাম ওয়েবসাইট — সেটআপ গাইড

এই ওয়েবসাইটটি সম্পূর্ণভাবে **GitHub Pages** (হোস্টিং) এবং **Google Sheets** (ডাটাবেস) দিয়ে চলবে। কোনো টাকা খরচ ছাড়াই সম্পূর্ণ ফ্রি।

## এখানে মাত্র ২টি ফাইল আছে
- **`index.html`** — সম্পূর্ণ ওয়েবসাইট (CSS+JS সব একসাথে, আলাদা ফোল্ডার লাগবে না) — এটাই GitHub এ আপলোড করবেন
- **`AppsScript_Code.gs`** — শুধু Google Sheets এর Apps Script এডিটরে পেস্ট করার জন্য (ফাইল হিসেবে আপলোড করার দরকার নেই)

GitHub এ শুধু `index.html` ফাইলটি (এবং চাইলে এই README) আপলোড করলেই চলবে — কোনো ফোল্ডার তৈরি করা লাগবে না, `Add file → Upload files` দিয়ে সরাসরি টেনে দিন।

---

## ধাপ ১: Google Sheet তৈরি করুন

1. [Google Sheets](https://sheets.google.com) এ গিয়ে একটি নতুন স্প্রেডশিট বানান। নাম দিন যেমন **"Student Forum Database"**।
2. উপরে মেনু থেকে **Extensions → Apps Script** এ ক্লিক করুন।
3. যে এডিটর খুলবে, সেখানে থাকা ডিফল্ট কোড মুছে দিয়ে এই প্রজেক্টের `AppsScript_Code.gs` ফাইলের সম্পূর্ণ কোড কপি-পেস্ট করুন।
4. উপরে থাকা **Save** (ফ্লপি ডিস্ক আইকন) এ ক্লিক করুন। প্রজেক্টের একটা নাম দিন, যেমন "Forum Backend"।
5. ফাংশন ড্রপডাউন থেকে **`setupSheets`** নির্বাচন করে **Run** বাটনে ক্লিক করুন।
   - প্রথমবার একটা পারমিশন চাইবে। **Advanced → Go to Forum Backend (unsafe) → Allow** ক্লিক করুন। (এটা আপনার নিজের স্ক্রিপ্ট, তাই নিরাপদ)
6. এটা রান হলে আপনার Google Sheet-এ স্বয়ংক্রিয়ভাবে সাতটি শীট তৈরি হয়ে যাবে: `Students`, `Teachers`, `Committee`, `SpecialCommittee`, `ForumInfo`, `Settings`, `Admin`।
7. Sheet-এ ফিরে গিয়ে `Settings` শীটে দেখুন `AdminPassword` এর মান `changeme123` আছে — এটা পরে ওয়েবসাইটের ব্যবস্থাপনা মেনু থেকে পরিবর্তন করে নেবেন।

## ধাপ ২: Web App হিসেবে Deploy করুন

1. Apps Script এডিটরে উপরে ডান দিকে **Deploy → New deployment** ক্লিক করুন।
2. গিয়ারের আইকনে ক্লিক করে **Web app** নির্বাচন করুন।
3. সেটিংস দিন:
   - **Execute as**: `Me (আপনার ইমেইল)`
   - **Who has access**: `Anyone`
4. **Deploy** ক্লিক করুন।
5. যে URL পাবেন (যেমন `https://script.google.com/macros/s/AKfycb.../exec`) সেটি **কপি করে রাখুন** — এটাই আপনার API URL।

> ⚠️ ভবিষ্যতে `AppsScript_Code.gs` ফাইলে কোনো পরিবর্তন করলে, **Deploy → Manage deployments → Edit (পেন্সিল আইকন) → Version: New version → Deploy** করে আবার আপডেট করতে হবে। URL একই থাকবে।

## ধাপ ৩: ওয়েবসাইটের config.js আপডেট করুন

`config.js` ফাইলটি খুলুন এবং এই লাইনটি খুঁজুন:

```javascript
API_URL: 'YOUR_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE',
```

এটি পরিবর্তন করে আপনার কপি করা URL বসান:

```javascript
API_URL: 'https://script.google.com/macros/s/AKfycb.../exec',
```

সংরক্ষণ করুন।

## ধাপ ৪: GitHub Pages এ হোস্ট করুন

1. [GitHub](https://github.com) এ একটি নতুন রিপোজিটরি বানান (যেমন `student-forum`)। **Public** রাখতে হবে।
2. এই প্রজেক্টের সব ফাইল (`index.html`, `config.js`, `css/`, `js/` ফোল্ডার) রিপোজিটরিতে আপলোড করুন।
   - GitHub ওয়েবসাইটে গিয়ে "Add file → Upload files" দিয়েও করা যায়, অথবা Git কমান্ড লাইন দিয়ে।
3. রিপোজিটরির **Settings → Pages** এ যান।
4. **Source**: `Deploy from a branch` নির্বাচন করুন।
5. **Branch**: `main` এবং ফোল্ডার `/ (root)` নির্বাচন করে **Save** করুন।
6. কয়েক মিনিট পর আপনার সাইট লাইভ হবে এই ঠিকানায়:
   `https://[আপনার-ইউজারনেম].github.io/student-forum/`

## ধাপ ৫: প্রথম লগইন ও তথ্য সেট করুন

1. লাইভ সাইটে গিয়ে **ব্যবস্থাপনা** মেনুতে ক্লিক করুন।
2. পাসওয়ার্ড দিন: `changeme123` (Sheet এর Settings ট্যাবে যা সেট করেছিলেন)
3. **ফোরাম তথ্য** ট্যাবে গিয়ে আপনার প্রতিষ্ঠানের নাম, লোগো, স্লোগান ইত্যাদি দিয়ে **সংরক্ষণ করুন**।
4. **পাসওয়ার্ড** ট্যাব থেকে ডিফল্ট পাসওয়ার্ড পরিবর্তন করে একটি শক্তিশালী পাসওয়ার্ড দিন।
5. **কমিটি তথ্য** ট্যাবে কমিটির সদস্যদের যোগ করুন (নাম লিখলে আগে থেকে রেজিষ্ট্রেশনকৃত শিক্ষার্থীদের নাম সাজেশন হিসেবে আসবে, নির্বাচন করলে মোবাইল নং অটো বসে যাবে)।

## ফাইল স্ট্রাকচার

```
student-forum/
├── index.html              ← মূল পাতা (সব মেনু এখানেই)
├── config.js                ← এখানে আপনার Apps Script URL বসাতে হবে
├── AppsScript_Code.gs        ← Google Sheet এ পেস্ট করার কোড (রিপোতে থাকবে শুধু রেফারেন্সের জন্য)
├── css/
│   └── style.css            ← ডিজাইন
└── js/
    ├── api.js                ← Google Sheet এর সাথে যোগাযোগ
    ├── app.js                 ← মূল লজিক, নেভিগেশন, ড্যাশবোর্ড
    ├── students.js            ← শিক্ষার্থী রেজিষ্ট্রেশন ও পোর্টাল
    ├── teachers.js            ← শিক্ষক রেজিষ্ট্রেশন ও পোর্টাল
    ├── admin.js               ← ব্যবস্থাপনা মেনু
    └── demo-data.js           ← ডেমো ডাটা (config.js সেট না করলে দেখাবে)
```

## গুরুত্বপূর্ণ নোট

- **ছবি আপলোড**: শিক্ষার্থী/শিক্ষকের ছবি ও স্বাক্ষর Google Drive-এ `StudentForumUploads` নামে একটি ফোল্ডারে সংরক্ষিত হবে (Apps Script যে Google অ্যাকাউন্ট দিয়ে ডিপ্লয় করেছেন, তার Drive-এ)।
- **ডেমো মোড**: যতক্ষণ `config.js`-এ সঠিক API URL না বসাবেন, ততক্ষণ সাইট নমুনা ডাটা দিয়ে চলবে — যাতে ডিজাইন দেখতে পারেন। এটি শুধু ব্রাউজারের মেমোরিতে থাকে, রিফ্রেশ দিলে হারিয়ে যাবে।
- **নিরাপত্তা**: এই পাসওয়ার্ড সিস্টেমটি সাধারণ (Sheet-ভিত্তিক)। এটি ছোট প্রতিষ্ঠানের জন্য যথেষ্ট, তবে অতি স্পর্শকাতর তথ্যের জন্য উপযুক্ত নয়। পাসওয়ার্ড কারো সাথে শেয়ার করবেন না।
- **সীমাবদ্ধতা**: Google Apps Script Web App প্রতিদিন ফ্রি অ্যাকাউন্টে প্রায় ২০,০০০ রিকোয়েস্ট পর্যন্ত সাপোর্ট করে — একটি প্রতিষ্ঠানের ফোরামের জন্য যথেষ্ট বেশি।
- **কাস্টম ডোমেইন**: পরবর্তীতে নিজস্ব ডোমেইন (যেমন `alfalahforum.com`) যুক্ত করতে চাইলে GitHub Pages Settings-এ Custom domain অপশন ব্যবহার করতে পারবেন — কোড পরিবর্তনের দরকার নেই।

## সমস্যা হলে

- সাইট লোড হচ্ছে কিন্তু ডাটা আসছে না → `config.js`-এ URL ঠিক আছে কিনা এবং শেষে `/exec` আছে কিনা দেখুন।
- "Unauthorized" এরর → Apps Script Deploy করার সময় "Who has access: Anyone" ঠিকমতো সেট হয়েছে কিনা চেক করুন।
- ছবি আপলোড না হলে → Google Drive-এ পর্যাপ্ত স্পেস আছে কিনা দেখুন।
